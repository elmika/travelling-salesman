# TSPLIB Problem Sources

## Primary Source

The `.tsp` files in this directory are EUC_2D instances from **TSPLIB95**, the standard benchmark
library for the Travelling Salesman Problem.

- **Original library**: Gerhard Reinelt, *TSPLIB — A Traveling Salesman Problem Library*,
  ORSA Journal on Computing, 3(4):376–384, 1991.
  <http://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/>

- **GitHub mirror used for download**:
  <https://github.com/mastqe/tsplib> (MIT-licensed collection of TSPLIB files)

Only EUC_2D instances (Euclidean 2D coordinates) are included. ATT, EXPLICIT, and other
weight-type variants were excluded because this solver works exclusively with 2D point sets.
